# Product Requirement Document (PRD) - nongslab.com

## Objective
Membangun dan mengembangkan landing page & portofolio digital agency Nongslab.com yang memamerkan hasil karya, keahlian teknis, serta mempermudah calon klien mengajukan proyek.

## Core Features & Sections Scope
1. **Hero Section:** Headline penawaran nilai utama, subheadline, dan CTA utama.
2. **Showcase / Selected Works:** Tampilan studi kasus proyek unggulan (mockup + penjelasan hasil/solusi singkat).
3. **Services & Capabilities:** Daftar penawaran layanan utama (Web Dev, UI/UX, Tech Advisory).
4. **Social Proof / Clients:** Testimonial atau logo brand/klien yang pernah ditangani.
5. **Contact / Inquiry Form:** Form pengajuan proyek singkat & integrasi kontak cepat.

## Out of Scope (YAGNI / Do Not Build)
- Sistem autentikasi / login user / dashboard admin internal (kecuali diminta eksplisit).
- Integrasi payment gateway langsung di landing page.
- Kompleksitas state management berlebihan (cukup React state lokal/lightweight).
